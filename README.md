# omega-media

Media files for Omega Console (a SillyTavern extension). Media only — no code.

| File | What |
| --- | --- |
| `journey-1.mp4` | Opening clip "The journey begins" (54 s · 1344×768 · H.264 + AAC) |

The Console fetches these files by their raw link, so never move, rename or delete a file while the Console points at it.
A new clip goes in as a new file.
